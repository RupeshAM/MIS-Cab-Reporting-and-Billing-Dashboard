# MIS-Cab-Reporting-and-Billing-Dashboard (with Slicer)
Excel MIS Report and Analytics Dashboard for Cab Duty Tracking, Vendor Costing, and Billing Analysis
An interactive Excel-based Management Information System (MIS) dashboard designed to automate cab duty tracking, vendor costing, gross billing analysis, and margin monitoring.

---

## 📊 Overview & Key Highlights

This project processes daily cab deployment data to provide actionable business insights regarding duty allocation, vendor management, and profit margins across clients.

- **Total Duty Tracking:** Tracks vehicle duty allocations across corporate clients.
- **Financial Analytics:**
  - **Gross Billed:** Total amount billed to clients.
  - **Vendor Cost:** Direct costs paid to cab vendors/suppliers.
  - **Gross Margin:** Net profit margin derived per client/route.
- **Interactive Filtering:** Integrated Slicers and Pivot Tables for dynamic multi-level filtering by Company Name, Date, and Duty Types.

## 🚀 How to Use

1. **Download the File:** Click on `MIS SHEET-JULY-26.xlsx` in this repository and click **Download**.
2. **Open in Excel:** Open the downloaded file in Microsoft Excel 2016 or newer.
3. **Interact with Dashboard:** Use the Slicers at the top to filter data dynamically by Company, Date, or Duty type.
